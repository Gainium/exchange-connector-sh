# 028 — plan

## Solution

1. `uta.ts`: `utaCollateralIsPooled(settings)` (unified + `multi_assets` +
   not `isolated`) and `pooledMarginFromUta(settings, assets)`
   (`max(0, effEquity − imr)` or `null`). Pure, unit-tested.
2. `BitgetExchange.getMarginAvailableUsd` overrides the abstract `null`:
   spot → `null`; classic (`accountMode()`) → `null`; settings read →
   `null` unless pooled; then the assets read, mapped by (1). Both reads go
   through `utaRequest` (limiter, profiler, retry policy).
3. main-app core (`main-app-sh`):
   - `bot/pooledMargin.ts` `widenByPool(available, poolUsd, coinm, price)` —
     linear uses the USD pool as is, COIN-M divides by price; only widens.
   - `MainBot.pooledMarginOrKeep(quoteAsset, available, price?)` no longer
     returns early for COIN-M; it skips COIN-M only without a price or for an
     isolated bot. DCA / Combo `checkBalance` pass `latestPrice`; grid
     `swapAssets` now consults it (futures only) when its check comes up short.
   - GraphQL `getPooledMarginAvailable(input: getLeverageInput!)`.
4. main-dash-redesign core: `botQueries.getPooledMarginAvailable`;
   `useVerifyTerminalBalance` asks it only for a COIN-M order the base coin
   cannot cover.

## Blast Radius

- Connector: Bitget only. `/marginAvailableUsd` gains a Bitget answer; its
  sole consumer is main-app's `pooledMarginOrKeep` /
  `spendableForNotEnoughBalance`. The latter gates on `!coinm` and a `USD`
  quote, and Bitget's linear pairs are USDT/USDC-quoted, so it never reads the
  Bitget figure.
- main-app: `pooledMarginOrKeep` now makes one `/marginAvailableUsd` call on
  the SHORT path of a COIN-M funds check, on every exchange (answered locally
  with `null` by every connector but Bitget and Kraken linear — no venue
  request). Grid swaps on Kraken flex also gain the pool, as DCA/Combo already
  had it.
- GraphQL: additive query; no existing field changes.
- Dashboard: one extra query only when a COIN-M terminal order would
  otherwise be refused. Deploy order is free: without the backend the query
  errors and the gate behaves as before.
