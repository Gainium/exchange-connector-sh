# 031 — plan

## Change

`src/exchange/exchanges/okx/index.ts` only:
- `xperpMap`, `xperpMapLoaded` become static. `xperpMapMissLoaded` becomes a
  static per-instFamily map. A static `xperpMapLoading` single-flights the
  fetch. A failed fetch is logged instead of being silently swallowed.
- The miss floor is stamped only when an otherwise usable map misses, so a
  cold load does not spend it.
- The four order-path `ensureXperpMap()` calls pass the pair.
- `handleOkxErrors` logs and invalidates on 51001.

JIT tier 0: the change stays inside the existing private helpers. Nothing new
is extracted.

## Blast radius

1. `ensureXperpMap` callers: the order paths above, plus leverage, candles
   (x2) and funding history. Those already pass hints and are unaffected
   beyond sharing the cache.
2. File is in `core/` (exchange-connector-sh, public). The parent pointer
   needs a bump. paper-trading does not share this code.
3. No `BaseReturn`, endpoint or Redis contract change.
4. The full mocha suite stays green. The existing okx specs (asset class,
   pooled margin) cover the neighbouring code.

The instFamily → instId mapping is identical on www/my/eea (checked live), so
one shared map is safe across `okxSource` values.
