## Change

- `src/exchange/helpers/orderFee.ts`: `FeeSign` type; `chargeMagnitude`
  becomes `signedCost(amount, sign)`; `normalizeOrderFees` sums signed cost per
  currency and drops currencies with net ≤ 0; `normalizeOrderFee` and
  `normalizeSidedOrderFee` take the convention. Header rule 2 corrected.
- Callers pass their convention:
  - `charge-positive`: binance, bybit (both paths), kucoin (both paths),
    coinbase, hyperliquid.
  - `charge-negative`: okx, bitget futures, bitget spot (`fees.ts`), bitget
    UTA.

JIT tier 0: pure helper, no I/O. Nothing new is extracted.

## Blast radius

1. Every venue mapper above. The argument is required, so tsc fails on a
   missed caller.
2. A charge on any venue gives the same output as before (same magnitude).
   Only rebate lines change.
3. The file is in `core/` (exchange-connector-sh, public). The parent needs a
   pointer bump. No `BaseReturn`, endpoint or Redis contract change. The
   `CommonOrder` fee fields keep their shape and meaning.
4. main-app already treats a missing fee as "use the estimate", so an omitted
   net rebate falls back the same way any unobserved fee does.
