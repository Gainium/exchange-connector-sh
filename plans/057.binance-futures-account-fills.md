# Plan 057 — Binance futures account fills

## Build order
1. `src/exchange/exchanges/binance/accountFills.ts`: pure origin classifier, trade mapper and the
   newest-first, cut-at-first-unattributed list builder. This is a new file and mirrors
   `bybit/accountFills.ts`.
2. `src/exchange/exchanges/binance/index.ts#getAccountFills`:
   - futures with a symbol only;
   - `userTrades` paging;
   - one `getOrder` per distinct order, newest first, capped at 20.
3. `abstractExchange.ts`, `exchange.service.ts` and `exchange.controller.ts`: thread the optional `symbol`.
4. Kraken, Bitget and Bybit `getAccountFills`: the signature gains an `_symbol` slot. Their retry handlers
   replay `(sinceMs, _symbol, timeProfile)`, because `timeProfile` must stay the last argument and the
   Binance handler splices the last argument.
5. `types.ts`: optional `realizedPnl` on `AccountFill`.
6. main-app core: pass the deal's symbol from `venueCloseEvidenceFor` (paired ship, after this one).

## Decisions the spec left open
- Attribute by `getOrder`, not `allOrders`. `allOrders` is window-filtered by order time, so a take-profit
  limit placed weeks before it filled would be missing from it. A per-order lookup has no such gap, and a
  close normally comes down to one or a few orders.
- Cut the list at the first unattributed trade rather than skip it. main-app walks fills newest first up to
  the deal size; a silently missing trade would let it count older fills in its place.
- An order placed by another API tool (not a bot) keeps its id and reads `API`. main-app then excludes it,
  and the deal stays "profit unknown" as before. That is conservative and unchanged.
- Fee in the quote coin only. The caller adds `fee` to a quote-coin result.

## Blast radius
- Callers of `getAccountFills` in main-app:
  - `venueCloseEvidenceFor` will send the deal symbol (paired change). Binance deals closed outside the bot
    are now priced from fills instead of "profit unknown". Liquidation pricing through the same evidence
    applies too.
  - `readLiquidationFills`, `settleWriteOffFromVenueFills`, `positionReconciler/orderProbe` and the Kraken
    repair script send no symbol, so Binance stays `[]` for them and the other venues are unchanged.
  - Nothing changes *when* a deal is judged closed outside the bot.
- Rate limit: per settled deal, ≤ 5 trade pages (weight 5/20 each) and ≤ 20 order lookups (weight 1). This
  only runs on the outside-close path.
- `core/` = exchange-connector-sh, shared. The parent pointer is bumped at push (`psh`). The parent's stale
  `src/` copy has no `getAccountFills`; parent `tsc` is clean.
- Other tests: the full core mocha suite (1291) is green, and core and parent `tsc` are clean.
