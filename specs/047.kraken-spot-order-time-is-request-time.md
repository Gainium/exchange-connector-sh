# 047 — Kraken spot order lookups report the request time as the order's times

Bug spec. Owner: `src/exchange/exchanges/kraken/index.ts` (spot `convertOrder` callers).
Sibling of spec 046 (the Futures path).

## 1. Definition

Expected: a Kraken spot order read back from the venue answers `transactTime` = when
Kraken opened it (`opentm`) and `updateTime` = when it closed (`closetm`: filled,
cancelled, expired), as every other venue does. `Date.now()` only when Kraken gives
no time.

Actual: no spot lookup passed a time to `convertOrder`, whose fallback is
`Date.now()`. Every answer said "this order was placed and last changed the instant
you asked", so a consumer comparing that time with another event (main-app's venue
order probe: did this fill land after its deal closed?) read every old order as new.

## 2. Evidence

Code: the QueryOrders (by txid, and its batch), open-orders scan, closed-orders scan,
`findSpotOrderByClOrdId` and `getAllOpenOrders` callers of `convertOrder` set neither
field although each row carries `opentm` (closed rows also `closetm`), in fractional
seconds. Runtime: the venue order probe's only Kraken spot row that carries a venue
time has `venueUpdateTime` exactly 1 ms before its own `checkedAt`, the same
signature spec 046 found on every Kraken Futures row.

## 3. Assumption

The callers drop times Kraken does return. Passing them through fixes the times and
nothing else.

### §2.1 Closed row: `updateTime` = `closetm`·1000, `transactTime` = `opentm`·1000.
### §2.2 Open row: `transactTime` = `opentm`·1000.
### §2.3 `getAllOpenOrders` rows carry `transactTime` = `opentm`·1000.
### §2.4 No close time: `updateTime` = `lastupdated`·1000 if the venue sends it, else `Date.now()` as before.
### §2.5 `krakenSpotOrderTimes` rounds fractional seconds to ms; missing, zero or non-numeric is no time.

Test: `src/exchange/exchanges/kraken/spot-order-venue-time.spec.ts`.

## 4. Out of scope

The batch-placement fallback for a txid Kraken has not yet read back keeps
`Date.now()`: no venue row exists there to read a time from.
